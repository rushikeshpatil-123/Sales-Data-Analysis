# Sales-Data-Analysis
## Project Overview
This project analyzes sales data using Python, Pandas, and Matplotlib to extract meaningful business insights.

## Objectives
- Load and analyze sales data
- Calculate total, average, maximum, and minimum sales
- Identify top-performing products and regions
- Visualize sales trends using charts

## Technologies Used
- Python
- Pandas
- Matplotlib
- Google Colab

## Key Findings
- Identified top-performing product categories
- Analyzed region-wise sales performance
- Generated business insights using data visualization
